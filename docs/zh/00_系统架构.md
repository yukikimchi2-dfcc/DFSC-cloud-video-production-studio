# 系统架构 · Cloud AI Video Production Studio

## 1. 总体架构

```
 Claude Code（云端会话）/ 团队成员（Codespaces）
            │  代码、配置、模板、文档、项目状态
            ▼
 GitHub Repository  ──CI──▶  自动测试 + 测试渲染 + Docker 镜像构建
            │
            ▼
 云端开发环境（可重建：Dockerfile / devcontainer / SessionStart hook）
   ├─ studio/ Python 引擎（Motion Graphics、AI 剪辑、QC、风格分析）
   ├─ workspace/   临时工作区（下载素材、渲染缓存、队列）—— 不进 git
   └─ renders/     版本化输出 —— 不进 git，上传至 Drive
            │                         ▲
            ▼                         │ 按需（须批准）
 Google Drive（素材库、预览、成品、QC 报告）   云端 GPU（RunPod / GCP，仅转写建议使用）
            │
            ▼
 团队审核与交付（项目状态流 + HANDOVER.md）
```

**持久化原则**：Claude Code 云端容器是**临时的**（会话结束会被回收）。所以：
- 代码 / 配置 / 项目状态 → **GitHub**（每次工作结束都要 commit + push）
- 影片、素材、成品 → **Google Drive**
- 任何人的电脑都不是主要工作环境

## 2. 代码结构

```
studio/
  config.py        分层配置：config/defaults.yaml → projects/<id>/project.yaml overrides
  brand.py         每个项目独立的品牌包（颜色、字体、Logo、动画规则）
  versioning.py    project_v001_preview.mp4 … 永不覆盖
  project.py       项目建立、状态流程、角色权限、活动记录、HANDOVER.md
  audit.py         环境审计（studio audit）
  cli.py           studio 命令
  core/            合成核心：canvas（合成）、timeline（图层/时间轴）、vector（矢量 Logo）、io（FFmpeg）、easing
  motion/          Motion Graphics Engine：typography、cards、camera、transitions、particles、stickers、templates
  edit/            AI 剪辑：transcribe、segments、speech_clean、reframe、subtitles、audio
  qc/              质量检测与报告
  style/           Video Style Intelligence：analyzer、profiles
  render/          renderer（Preview/Final）、queue（队列/重试/分段缓存）、demo（合成测试素材）
  storage/         Store 接口：drive（Google Drive）、local（本地）、index（素材索引）
  gpu/             付费 GPU 成本守门
config/            defaults.yaml（渲染默认值）、roles.yaml（角色与状态流程）
projects/<id>/     project.yaml、brand/、activity.jsonl、HANDOVER.md
templates/<id>/    template.yaml + 预览图
style_profiles/    风格档案（APPROVED / REFERENCE_ONLY / REJECTED / UNREVIEWED）
tools/             extract_ai_assets.py（从 .ai 主视觉提取矢量 Logo）
tests/             自动测试（pytest）
docs/zh/           中文文档
```

## 3. 渲染核心的约定

- 所有图层几何以 **1080×1920 设计坐标**编写，`ctx.px()` 自动缩放；同一份设计可直接渲染 720p Preview 或 1080p Final。
- 帧为 float32 RGB；图层回传 RGBA `Patch`（带位置），由时间轴依 `z` 顺序合成。
- 两类图层：内容图层（`render()` 回传 Patch）与整帧图层（`draw()` 处理整帧：运镜、转场、调色）。
- 编码一律经由 FFmpeg 管线（libx264），音频响度以两段式 `loudnorm` 处理。

## 4. 品牌与风格隔离

- 每个项目有自己的 `brand/brand.yaml`；模板只引用**颜色角色**（primary / background / text …）与**字体角色**（title / body / subtitle …），因此同一模板套用不同品牌会自动换装。
- 风格档案必须经人工审核为 `APPROVED` 才能成为品牌标准；分析结果一律从 `UNREVIEWED` 开始。

## 5. 安全与权限

- 凭证只放环境密钥 / `secrets/`（git-ignored），从不进 git。
- Drive：只新增、不删除、不移动；同名上传会成为新文件；所有传输比对 MD5。
- 付费 GPU：`studio/gpu/guard.py` 无批准一律拒绝。
- 项目状态变更受 `config/roles.yaml` 的角色权限控制，所有变更记录于 `activity.jsonl`。
